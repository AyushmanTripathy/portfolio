## Design Context

### Users
Fellow developers and recruiters browsing the portfolio. Developers appreciate the CLI aesthetic and technical details; recruiters look for skills and projects.

### Brand Personality
Technical, authentic, slightly playful. The CLI theme should feel like a natural extension of a developer's environment - not forced, but genuine.

### Aesthetic Direction
- **Theme**: Dark mode only
- **Palette**: Various shades of gray (not pure black #000000 or pure white #ffffff)
- **Font**: Monospace throughout (JetBrains Mono is already in use)
- **Visual elements**: Terminal/CLI aesthetic - ASCII art, command-line style content presentation
- **Tone**: Raw, utilitarian, unpolished in a deliberate way - like a well-crafted dotfiles setup

### Design Principles
1. **Authentic CLI feel** - Content presented as if from a terminal (commands, output, file listings)
2. **Gray-only palette** - No colored accents; let structure and typography do the work
3. **Minimal decoration** - No unnecessary visual elements; every pixel earns its place
4. **Typography-driven hierarchy** - Use font weights, sizes, and spacing for emphasis, not colors or borders
5. **Performance first** - Fast load times, no heavy animations, practical over decorative
